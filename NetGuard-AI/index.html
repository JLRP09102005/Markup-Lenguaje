Capacidades del sistema

📡
01.

Captura de Paquetes

Integración con nmap via PHP exec(). Descubrimiento de hosts, puertos abiertos y fingerprinting de servicios en la red local.

🧠
02.

Motor IA — Isolation Forest

Modelo entrenado con CICIDS2017. Detecta anomalías sin firmas: DoS, Port Scan, Brute Force, Infiltration y Botnet.

🔬
03.

Deep Packet Inspection

Análisis de cabeceras TCP/UDP/ICMP. Extracción de features para el modelo: packet length, flag ratios, inter-arrival time.

⚡
04.

Alertas en Tiempo Real

Dashboard PHP con polling cada 3s. Clasificación por severidad crítica, alta, media e informativa con timestamps exactos.

🛡️
05.

Respuesta Asistida

El modelo sugiere reglas iptables y fail2ban. El administrador aprueba con un click antes de aplicar el cambio al sistema.

📊
06.

Visualización & Auditoría

Gráficas Chart.js de tráfico histórico y picos anómalos. Log forense persistente en SQLite de todos los eventos.

── 0x03.5 · DEMO UI ──
// interfaz en acción

Dashboard diseñado para analistas

Cada elemento de la interfaz está pensado para reducir el tiempo de respuesta ante amenazas. Información crítica al frente, ruido eliminado.

UI·01

Tabla de paquetes en tiempo real

Filas coloreadas por severidad al estilo Wireshark. Cada paquete anómalo es marcado al instante con su anomaly score.

UI·02

Panel de métricas vivas

Contador de hosts activos, paquetes analizados y alertas pendientes actualizado cada 3 segundos via polling PHP.

UI·03

Gráfica de tráfico histórico

Barras Chart.js que muestran volumen de paquetes por minuto. Los picos anómalos se destacan en rojo automáticamente.

UI·04

Log de alertas con acción 1-click

Cada alerta incluye botones de "Bloquear IP" y "Ignorar". La acción se envía via API Flask al sistema iptables local.
